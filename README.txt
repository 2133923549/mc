# Archive World

# Archive World（归档世界）

A Minecraft Forge mod that creates a shared world space between different saves.

一个 Minecraft Forge 模组，用于创建一个可以跨存档共享的独立世界空间。


## Introduction

## 简介

Archive World allows players to keep their creations in a separate world that can be accessed from multiple Minecraft saves.

Archive World 允许玩家将自己的建筑保存到一个独立世界中，并在多个 Minecraft 存档之间访问。


The purpose of this mod is simple:

这个模组的目标很简单：

Build once, keep forever.

建造一次，永久保存。


Your creations are no longer limited to a single save file.

你的建筑不再局限于某一个存档。


## Core Features

## 核心功能

### Shared Archive World

### 共享 Archive World

Archive World is an independent world separated from normal survival worlds.

Archive World 是一个独立于普通存档的世界。


Any blocks placed inside Archive World will remain available when entering from another save.

在 Archive World 中放置的方块，会在其他存档进入时保持存在。


Example:

示例：
Save A
|
| Build a castle
↓
Archive World
|
↓
Save B
|
| The castle is still there


## Design Concept

## 设计理念

Archive World is designed as a personal construction space.

Archive World 被设计为玩家自己的建筑空间。


It is not a replacement for normal worlds.

它不是普通世界的替代品。


Instead, it provides a permanent place to store important creations.

而是提供一个永久保存重要建筑的位置。


## Installation

## 安装方式

Minecraft:
1.20.1

Loader:
Forge


1. Install Forge.

   安装 Forge。

2. Put the mod jar into the mods folder.

   将 jar 文件放入 mods 文件夹。

3. Start Minecraft.

   启动游戏。
